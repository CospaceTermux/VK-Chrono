# История изменений (Changelog)

## [v1.3.0] — 2026-08-18

### Изменено и добавлено:
* Интеграция с Google Drive через протокол OAuth 2.0 (пользовательские учетные данные `credentials.json` и `token.json`): устранено ограничение на нулевую квоту хранилища для сервисных аккаунтов.
* Полный тихий режим работы (Silent Mode): отключена отправка сообщений и оповещений ботом в целевую беседу ВКонтакте.
* Добавлена зависимость `google-auth-oauthlib` в `requirements.txt`.

## [v1.2.0] — 2026-08-16

### Добавлено:
* Интеграция с Google Drive:
  * Автоматическая выгрузка HTML-отчетов в целевую папку на Google Диске через Google Service Account API или локальный клиент.
  * Команда CLI `test-gdrive` для валидации соединения и проверки прав доступа к папке.
* Поддержка репостов и расширенных вложений ВКонтакте:
  * Обработка репостов записей со стены (wall) с извлечением текста, автора и ссылки на пост.
  * Обработка внешних ссылок, видеозаписей и статей.
  * Отображение репостов и пересланных сообщений в HTML-отчете и их учет в промптах Gemini.

## [v1.1.0] — 2026-08-16

### Добавлено:
* Поддержка голосовых сообщений:
  * Локальное сохранение аудиофайлов в формате MP3.
  * Интеграция с автоматической транскрибацией речи ВКонтакте.
  * Учет текста голосовых сообщений в контексте AI-анализа.
  * Встроенный аудиоплеер и отображение расшифровки в HTML-отчетах.
* Локальное сохранение прикрепленных фотографий и их встраивание в HTML-отчеты.
* Переработка промптов суммаризации: формирование хронологического таймлайна событий с таймкодами и выделение ключевых тезисов.
* Автоматическая отправка уведомлений в беседу ВКонтакте по завершении дневной и месячной компиляции.

## [v1.0.0] — 2026-08-16

### ✨ Основные возможности:
* **Моментальный захват переписки (Flight Recorder)**:
  * Прослушивание сообщений через VK Bots LongPoll API в режиме реального времени.
  * Сохранение сообщений в SQLite базу данных с поддержкой WAL-режима (Write-Ahead Logging).
  * Поддержка всех типов сообщений: текст, вложения, цитирование (ответы), пересланные сообщения, стикеры.
* **Локальное кэширование профилей и медиа**:
  * Автоматическое скачивание и кэширование аватарок участников (`data/avatars/`).
  * Скачивание прикрепленных фотографий на диск в высоком разрешении (`data/photos/`).
* **Интеллектуальная AI-суммаризация (Google Gemini `gemini-3.6-flash`)**:
  * Составление хронологического таймлайна ключевых событий дня с таймкодами.
  * Выделение главных тезисов, инсайтов, принятых решений и задач.
  * Полная мультиязычность (`ru`, `en`, `auto`) с корректным сохранением технических терминов и ссылок.
  * Встроенный эвристический fallback на случай отсутствия API-ключа или проблем с сетью.
* **Автономные адаптивные HTML и Markdown отчеты**:
  * Премиальный дизайн в стиле современного мессенджера.
  * Встроенная темная и светлая темы с переключением в 1 клик.
  * Быстрый поиск по сообщениям и фильтрация по авторам.
  * Вшивание аватарок и фото в `base64` (отчеты открываются офлайн без интернета).
* **Многоуровневая агрегация**:
  * Ежедневное закрытие дня в 00:00:10.
  * Недельные дайджесты (каждые 7 дней).
  * Месячные архивы (летопись месяца).
* **Уведомления в беседу ВКонтакте**:
  * Оповещение при успешном сохранении дня: *«Бот успешно сохранил сообщения за ДД.ММ.ГГГГ, продолжайте в том же духе!»*.
  * Оповещение при создании месячной сводки с ссылкой на репозиторий.
* **Автоматическая синхронизация с GitHub**:
  * Авто-создание репозитория и мгновенная выгрузка отчетов через GitHub REST API.
  * Поддержка GitHub Pages для онлайн-просмотра отчетов.
* **CLI-инструменты**:
  * Команды `start`, `compile-day`, `compile-week`, `compile-month`, `aggregate-all`, `test-github`, `simulate`.
