# VK Chrono - Бот логирования бесед VK с AI-суммаризацией

Автономный бот для сообщества ВКонтакте, который:
1. Логирует все сообщения из бесед с профилями участников (имя, фамилия, кэш аватарок).
2. Формирует ежедневные отчеты в формате **HTML (в стиле современного чата)** и **Markdown**.
3. Создает умные структурированные сводки за день с помощью **Google Gemini** (`gemini-3.6-flash`): темы, решения, договоренности, топ участников.
4. Автоматически объединяет дни в **недельные дайджесты** (каждые 7 дней) и **месячные архивы** (в конце месяца).

---

## Архитектура проекта

```
vk-chrono/
├── config.py                 # Конфигурация (.env: VK_TOKEN, GEMINI_API_KEY, PEER_ID и др.)
├── .env.example              # Шаблон файла настроек
├── database.py               # SQLite хранилище: пользователи, сообщения, агрегированные отчеты
├── vk_client.py              # Клиент VK Bots LongPoll API, кэширование профилей и аватарок
├── summarizer.py             # Модуль суммаризации на базе Google Gemini API (Interactions API)
├── renderer.py               # Jinja2-шаблонизатор для автономных HTML и MD отчетов
├── aggregator.py             # Сервис объединения: день -> 7 дней (неделя) -> месяц
├── scheduler.py              # Фоновый планировщик APScheduler (полуночный запуск, авто-компиляция)
├── main.py                   # Главная точка входа + CLI команды (run, compile-day, compile-week, simulate)
├── templates/
│   ├── base.html             # Стильный базовый шаблон чата с фильтрами и поиском
│   ├── daily_report.html     # Дневной отчет с карточкой AI-сводки
│   ├── weekly_report.html    # Недельный дайджест с разбивкой по дням
│   └── monthly_report.html   # Месячный сводный архив
├── data/
│   ├── chat_logger.db        # SQLite база
│   ├── avatars/              # Кэшированные аватарки пользователей (.jpg)
│   └── reports/
│       ├── daily/            # Дневные HTML/MD отчеты
│       ├── weekly/           # Недельные HTML/MD отчеты
│       └── monthly/          # Месячные HTML/MD отчеты
└── requirements.txt          # Python зависимости
```
