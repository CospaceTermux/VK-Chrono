# 🚀 VK Chrono — Бот логирования бесед VK с AI-сводками и агрегацией

Автономный бот для бесед ВКонтакте, который логирует сообщения, сохраняет профили и аватарки участников, создает стильные ежедневные **HTML и Markdown отчеты** со сводкой через **Google Gemini**, а также автоматически объединяет их в **недели** (каждые 7 дней) и **месяцы**.

---

## ✨ Возможности

- **Полное сохранение переписки**: Имена, фамилии, кэш аватарок пользователей, текст, вложения (фото, документы, голосовые, стикеры), ответы и пересланные сообщения.
- **Автономные HTML-отчеты**: Премиум-дизайн в стиле чата с темной и светлой темой, встроенными в base64 аватарками (открываются офлайн без интернета), поиском и фильтрацией по авторам.
- **AI-Суммаризация (Google Gemini API)**:
  - 🎯 Главные темы дня/недели/месяца;
  - ✅ Принятые решения и договоренности;
  - 👥 Активность и вклад ключевых участников;
  - 🎭 Тональность и атмосфера.
- **Многоуровневая агрегация**:
  - **Дни**: закрываются в полночь (в 00:00:10);
  - **Недели**: при накоплении 7 дней формируется дайджест недели с выжимками каждого дня;
  - **Месяцы**: в конце месяца компилируется архив с обзором всех недель.
- **Эвристический Fallback**: если API-ключ Gemini не указан, бот создает информативную структурированную сводку на основе статистики.

## 🛠️ Установка и запуск

### 1. Настройка переменных окружения
Скопируйте шаблон `.env.example` в `.env`:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
* `VK_TOKEN` — ключ доступа сообщества ВКонтакте с правами на сообщения.
  *(Сообщество → Управление → Работа с API → Ключи доступа → Создать ключ)*
* `VK_GROUP_ID` — ID вашего сообщества (число).
* `TARGET_PEER_ID` — ID беседы (число, например `2000000001`). Если `0` — логирует все беседы.
* `GEMINI_API_KEY` — ключ API Google Gemini (получить на [Google AI Studio](https://aistudio.google.com/app/apikey)).

### 2. Запуск бота в реальном времени
```bash
.\.venv\Scripts\python.exe main.py start
```

## 🐙 Автоматическое сохранение в GitHub (Опционально)

VK Chrono умеет автоматически выгружать каждый готовый дневной, недельный и месячный отчет прямо в ваш GitHub репозиторий через GitHub API (без необходимости локального `git push`).

### Как настроить:
1. Создайте [Personal Access Token на GitHub](https://github.com/settings/tokens) с правами `repo`.
2. В файле `.env` укажите:
   ```ini
   GITHUB_ENABLED=true
   GITHUB_TOKEN=ghp_ваш_токен_github
   GITHUB_REPO=ваш_username/ваш_репозиторий
   GITHUB_BRANCH=main
   GITHUB_PATH_PREFIX=reports
   ```
3. Проверьте подключение:
   ```powershell
   .\.venv\Scripts\python.exe main.py test-github
   ```
4. Теперь каждый скомпилированный отчет (HTML и Markdown) будет мгновенно коммититься и пушиться в ваш GitHub репозиторий! 

> 🌐 **Бонус:** Если включить **GitHub Pages** в настройках вашего репозитория, вы сможете читать логи и дайджесты беседы прямо по ссылке в браузере (например, `https://username.github.io/repo/reports/daily/day_...html`)!

## 🧪 Тестирование и команды CLI

### Запуск симуляции 7-дневного диалога:
Создает виртуальных участников, генерирует историю сообщений и запускает компиляцию: день -> 7 дней (неделя) -> месяц:
```bash
.\.venv\Scripts\python.exe main.py simulate --days 7
```

### Ручная компиляция конкретного дня:
```bash
.\.venv\Scripts\python.exe main.py compile-day --date 2026-08-16 --peer 2000000001
```

### Принудительная агрегация всех накопленных данных:
```bash
.\.venv\Scripts\python.exe main.py aggregate-all --peer 2000000001
```

## 📁 Структура отчетов

* `data/reports/daily/` — Дневные отчеты `day_{peer_id}_{date}.html` и `.md`
* `data/reports/weekly/` — Недельные дайджесты `week_{peer_id}_{week_key}.html` и `.md`
* `data/reports/monthly/` — Месячные архивы `month_{peer_id}_{month_key}.html` и `.md`
* `data/avatars/` — Локальный кэш аватарок пользователей `{user_id}.jpg`
